---

사용자가 `/github-setup` 를 실행했다.

**반드시 `github-setup` 스킬을 로드해, 그 안에 정의된 절차·분기·질문 문구·선택지를 한 글자도 바꾸지 말고 그대로 따른다.** 이 커맨드 본문에서 절차나 질문을 새로 만들거나 요약하지 말 것:

- **분기·질문 문구·옵션은 스킬이 정본이다.** 여기 표현으로 지어내거나 줄이지 않는다.
- 사용자에게 묻는 선택지(예: 가입 여부)는 **반드시 스킬 지시대로 `AskUserQuestion` 선택형으로 띄운다. 텍스트로 나열하지 말 것.**
- 감지/등록 스크립트는 플러그인 번들(`$CLAUDE_PLUGIN_ROOT/skills/github-setup/scripts/`)이다. **현재 작업 폴더에 없는 게 정상**이며, cwd에서 찾거나 위치를 되묻지 않는다.
- 자격증명(토큰·비밀번호)을 요구·출력·기록하지 않는다.

모든 응답은 한글, 비개발자가 이해할 수 있게 쉽게. 링크는 한글 하이퍼링크 없이 URL을 그대로 보여준다.
