---
description: 배포 전 검토 — 보안 + 배포 가능성 두 축을 점검하고 HTML 리포트를 만든다.
---

사용자가 `/deploy-check` 를 실행했다. 배포 전 검토를 시작한다.

**`security-review` 스킬을 사용해** 처리하라. 스킬의 절차를 그대로 따른다:
- 검토 대상은 **현재 프로젝트 폴더**가 기본(사용자가 다른 경로를 명시한 경우에만 그걸 쓴다).
- 0토큰 엔진 실행 → 보안(🔒) + 배포가능성(🚀) 두 축 해석 → **검토 결과를 배포 시스템에 등록**(`scripts/verdict-upload.sh`) → **항상 HTML 리포트** 생성.
- 결과는 "통과 / 주의 / 차단"(보안), "배포 준비 완료 / 배포 불가"(배포가능성)로 쉽게 전한다.

모든 응답은 한글, 비개발자가 이해할 수 있게 쉽게.
