description: 배포 전 검토 — 보안 + 배포 가능성 두 축을 점검하고 HTML 리포트를 만든다.
---

사용자가 `/deploy-check` 를 실행했다.

**반드시 `security-review` 스킬을 로드해, 그 안의 절차를 `1)` 단계부터 순서대로 한 글자도 빼지 말고 따른다.** 이 커맨드 본문에서 절차를 요약·재구성하지 말 것 — 아래는 위임 규칙일 뿐, 여기서 단계를 새로 만들지 않는다:

- **검토에는 배포 키가 필요 없다 — 키를 요구하거나 차단하지 말 것.** 키 확인·서버 등록은 모두 `/deploy` 가 한다. 검토는 엔진+심화+산출물+로컬 HTML 리포트까지만 하고, "이 결과는 `/deploy` 할 때 서버에 등록·배포돼요"라고 안내한다.
- 시크릿/git 이력 판정은 **0토큰 엔진(`fdh-engine`)을 직접 실행**해 그 JSON으로 한다. **수동으로 `.env` 를 들여다보거나 직접 시크릿 스캔해서 판정하지 않는다**(엔진이 authoritative — gitignore+dockerignore로 제외된 `.env` 비밀은 finding 아님).
- 리포트는 **반드시 번들 `render-report.sh` + 템플릿으로만** 만든다. **HTML을 손으로 작성하거나 `artifact-design` 등 다른 스킬을 부르거나 Artifact로 발행하지 않는다.**
- 검토 대상은 현재 프로젝트 폴더가 기본(다른 경로를 명시한 경우에만 그걸 쓴다).

모든 응답은 한글, 비개발자가 이해할 수 있게 쉽게.
