---
description: 배포 키를 등록하거나 새 키로 교체한다 (~/.fursys/proxy-key 에 저장).
---

사용자가 `/set-key` 를 실행했다. 개인 배포 키를 등록/교체한다.

1. 사용자가 키를 아직 주지 않았으면 요청한다: "IT본부에서 받은 개인 배포 키(`fdh_live_` 로 시작하는 49자)를 붙여넣어 주세요."
2. 받은 키로 `deploy` 스킬에 번들된 `scripts/key-set.sh "<붙여넣은 키>"` 를 실행한다.
   - **보안 철칙: 키 전체 값은 화면에 다시 출력하지 않는다.** 스크립트도 앞 12자까지만 돌려준다.
3. 결과 코드 해석:
   - `SAVED <앞12자>` → "배포 키를 저장했어요(앞부분: `<앞12자>`). 이제 '배포해줘' 나 `/my-apps` 가 바로 동작해요."
   - `ENV_OVERRIDE <앞12자>` → "파일에는 저장했지만, 환경변수 `FURSYS_PROXY_KEY` 가 설정돼 있어 **그게 우선 적용**돼요. 방금 넣은 키를 쓰려면 그 환경변수를 지워야 해요."
   - `BAD_FORMAT` → "키 형식이 올바르지 않아요. `fdh_live_` 로 시작하고 총 49자여야 해요. IT본부에서 받은 키를 다시 확인해 주세요." (저장하지 않았음)
   - `NO_INPUT` → 키를 다시 요청한다.

모든 응답은 한글, 비개발자가 이해할 수 있게 쉽게.
