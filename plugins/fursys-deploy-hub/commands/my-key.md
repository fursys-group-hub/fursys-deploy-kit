---
description: 내 배포 키 상태를 확인한다 (등록 여부·형식·앞부분만 — 전체 값은 보여주지 않는다).
---

사용자가 `/my-key` 를 실행했다. 본인의 개인 배포 키 상태를 확인해 알려준다.

`deploy` 스킬에 번들된 `scripts/key-status.sh` 를 실행해 결과를 받는다.
- **보안 철칙: 키 전체 값은 절대 화면에 보여주지 않는다.** 스크립트도 앞 12자(`fdh_live_xxx`)까지만 돌려준다 — 그대로만 노출한다.
- 결과 코드 해석:
  - `NO_KEY` → "아직 배포 키가 등록돼 있지 않아요. 키가 없으면 `/get-key` 로 발급을 신청하고, 이미 받았으면 `/set-key` 로 등록하면 돼요."
  - `KEY_FILE <앞12자> <YES|NO>` → 키가 파일(`~/.fursys/proxy-key`)에 저장돼 있음. 앞부분만 보여주고, 형식이 `YES`면 "정상 형식이에요", `NO`면 "형식이 올바르지 않아요 — IT본부에서 받은 키를 다시 확인해 `/set-key` 로 등록해 주세요"라고 안내.
  - `KEY_ENV <앞12자> <YES|NO>` → 키가 환경변수 `FURSYS_PROXY_KEY` 에 설정돼 있음(파일보다 우선 적용). 형식 안내는 위와 동일.
  - `KEY_BOTH <앞12자> <YES|NO>` → 파일·환경변수 둘 다 있고 **환경변수가 우선** 적용됨을 알린다. 보여주는 앞부분은 실제 적용되는(환경변수) 키 기준이다.

모든 응답은 한글, 비개발자가 이해할 수 있게 쉽게.
